They are detecting you're a bot`: headless chromium, headed chromium, headless webkit, and headless/headed chromium carrying the operator's real `msToken` read from the logged-in Chrome profile. TikTok blocks the library's signed `challenge/item_list` request at the API level. What the library *would* have given us if it worked (read from its source): arbitrary hashtags with deep cursor pagination (`hashtag.videos(count=N)` - the one capability that would widen the view spread), per-account videos, sound/playlist videos, comments and related videos, and a For-You `trending.videos()` feed that cannot be region-scoped. It does NOT offer keyword-to-video search (its `search` module is users-only; video search needs auth) and, like everything else, has no view-range query. The venv and the Playwright browsers (~150 MB in `%LOCALAPPDATA%\ms-playwright`) were left in place but are gitignored; the temporary msToken file was deleted.
